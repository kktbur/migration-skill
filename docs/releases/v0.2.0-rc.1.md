# Migration Skill v0.2.0-rc.1

Status: Experimental / Release Candidate

This is the first installable skills-only Codex Plugin release candidate. It
packages the canonical raw Skill without adding an LLM SDK, MCP server, or
independent Agent Runtime.

## Verified in this repository

- Skills-only Codex Plugin packaging and raw Skill compatibility;
- local marketplace installation and discovery;
- installed verifier replay;
- Contract / Judge / Freeze / Ratchet protocol;
- Plugin upgrade mismatch detection and rollback;
- uninstall/reinstall preservation of migration evidence;
- frozen verifier protection and resume preflight;
- three published migration benchmarks with broken-Target rejection;
- offline regression harness and benchmark-only dependency isolation.

## Pending release gate

- model-backed Plugin invocation in a fresh Codex session on a clean host;
- explicit Skill invocation and natural-language implicit invocation;
- one Agent-generated Plugin dogfood migration from an empty Target;
- final frozen Judge result for that host-backed dogfood run.

The remaining host validation is tracked separately in [Issue #16](https://github.com/kktbur/migration-skill/issues/16).
The current transport blocker is not addressed by weakening Migration Skill
verification or disabling TLS validation.

## Compatibility

This release candidate uses Contract schema `2` and Freeze schema `3`. See
[`docs/plugin-compatibility.json`](../plugin-compatibility.json) for the
machine-readable policy.

This release is not presented as stable, production-ready, or a guarantee of
arbitrary one-click repository migration.
